# YIKEOO 英语学习基地

YIKEOO English Base 是一个从零开始的静态英语学习网站。课程按用户的实际使用场景规划：熟悉设备与常用软件、练习生活口语、学习 AI 专业词汇，之后扩展阅读和词汇量。音标、口型、重音和语流练习贯穿每个阶段。

## 本地预览

直接用浏览器打开 `index.html` 即可。网站没有构建步骤或第三方依赖。

## 文件

- `index.html`：首页、发音入门和学习路线
- `style.css`：样式与响应式布局
- `stars.js`：星轨背景动画
- `learning.js`：第一课、测验和本地学习进度
- `speeches/`：演讲目录、视频、中英对照和单词朗读；演讲条目维护在 `speeches/data.js` 中
- `orbit-mark.svg`、`favicon.svg`：网站图标

学习进度保存在当前浏览器的本地存储中，不会在设备间同步。发音提示目前以音标和口型讲解为主，课程语音会在选定合适的示范音色后再加入。

演讲页的句子和单词发音使用浏览器自带语音，声音和可用性依设备而异；长按单词可查询词性、音标与中文参考释义，使用 Free Dictionary API 和 MyMemory，仅向这两个服务发送所选单词；视频使用来源方播放器，并提供原视频链接。特朗普、乔布斯、蒂姆·库克和希拉里演讲提供完整原稿中英对照，马云目前为精选短句。库克和乔布斯的文件是预备稿，可能与视频措辞不同；希拉里原稿包含蒂姆·凯恩的介绍。
